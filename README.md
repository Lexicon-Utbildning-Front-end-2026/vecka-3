Dessa ska sen länka vidare till receptsidorna (ni behöver inte göra fler receptsidor utan ni kan länka enbart till den ni har redan).

## 📅 Fredag: Code Review

### 🎯 Mål för dagen
Fördjupa förståelsen av veckans begrepp genom att prata kod.

Frågor för Code Review:
* **I grupp:** Visa och förklara för de andra i gruppen hur du använt flex och grid i din kod. Motivera också varför du valt den ena framför den andra och om du i efterhand skulle gjort något annorlunda.
* **Gemensamt:** Vad är svårast med att förklara sin kod för andra och vad är svårast när man försöker förstå andras kod?
